# The report and GitHub Pages

## Report sections

| Section | Content |
|---|---|
| Header | base and head, diff size, documentation source, the detected site (generator, base URL, deploy method), warnings |
| `## Impacts` | One row per section and adjustment: `path#anchor`, published URL, adjustment, confidence, the matching terms with their change (`removed`, `added`, `changed`), the code file and line that caused it |
| `## Undocumented additions` | New public flags, environment variables, routes and symbols that no section mentions |
| `## Navigation` | New pages the site navigation does not list, with their URL; or why the check was skipped |
| `## Already updated in this branch` | Impacted sections whose file the branch already edits; not pending |
| `## Review context` | Numbered list: each affected page with the code files to read beside it |

**Adjustments**: `update` (a renamed element, the old name has a successor nearby in the same file, or a changed
value: revise the text), `obsolete` (a removed element with no successor: the text about it goes), `check` (a declared
mapping with no shared term: read the section against the change).

**Confidence**: `high` for a rename, a removal, or a term match inside a declared mapping; `medium` for a changed
value; `low` for a mapping-only `check`. Rows are sorted by confidence, then by the number of terms.

An empty report says "No documentation impact found." That means no shared term, no mapping, no new public element and
no navigation gap: it does not cover behaviour described only in prose.

## What is detected

The scanner looks at the documentation source, in this order, and uses the first match:

| Generator | Configuration | Navigation read from |
|---|---|---|
| Docusaurus | `docusaurus.config.{js,ts,mjs,cjs}` (`url`, `baseUrl`) | `sidebars.*`; none when the sidebar is autogenerated |
| MkDocs | `mkdocs.yml` (`site_url`, `docs_dir`, `use_directory_urls`) | the `nav:` block; none when there is no `nav:` |
| Jekyll | `_config.yml` at the root or in `docs/` (`url`, `baseurl`) | none (Jekyll has no central navigation) |
| Static | a Pages deploy workflow, a `gh-pages` branch or a `CNAME` file | none |

The deploy method is `actions` (a workflow using `actions/deploy-pages`, `peaceiris/actions-gh-pages` or `mkdocs
gh-deploy`), `branch` (a `gh-pages` branch) or `unknown`.

## URL rules

Base URL: the generator's configured site URL, else the host in `CNAME`, else `https://<owner>.github.io/<repo>/`
from the `origin` remote (just `https://<owner>.github.io/` for a repository named `<owner>.github.io`). With none of
these, the report has no URLs.

Page URL, for `docs/api/refunds.md` on a site with base `https://example.github.io/payments/`:

| Generator | URL |
|---|---|
| MkDocs (`docs_dir: docs`, directory URLs) | `https://example.github.io/payments/api/refunds/` |
| MkDocs, `use_directory_urls: false` | `https://example.github.io/payments/api/refunds.html` |
| Docusaurus | `https://example.github.io/payments/docs/api/refunds` |
| Jekyll | `https://example.github.io/payments/docs/api/refunds.html`, or the page's `permalink` |
| Static | `https://example.github.io/payments/api/refunds.html` for `.html`/`.htm` sources only; any other format has no URL |

`index.md`, and `README.md` outside Jekyll, map to their directory. Section rows add `#anchor`.

## Navigation check

For each page the branch adds or renames under the docs directory, the scanner checks that the navigation lists it. A
page missing from the navigation is published but not reachable from the menu. The check runs only when the
navigation is explicit (an MkDocs `nav:`, a hand-written Docusaurus sidebar) and only when the documentation lives in
this repository.

## Limits

- No site is built and no link is followed: broken links, redirects, versioned docs, translations and theme
  overrides are not checked.
- Configuration is read with line patterns, not a YAML or JavaScript parser; values computed at build time
  (environment variables, imports) are not seen, and the defaults apply.
- Anchors follow the common slug rule (lowercase, punctuation dropped, spaces to hyphens); a generator with custom
  slugs may differ.
